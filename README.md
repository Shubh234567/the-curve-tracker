# The Curve Collection Tracker

Flat-wise collection tracker for The Curve, 54 Chowringhee Road, Kolkata.

Tracks the 11 Schedule D payment stages for each flat, GST (5%), buyer TDS (1%, 194-IA), the Developer 32.5% / Owner 67.5% split, and recovery of the ₹20 Cr landowner deposit. It can export and import a 7-sheet Excel workbook with live formulas.

## Running it

Open `index.html` in a browser. Outside Claude, data is saved in that browser only (localStorage). Use **⭳ JSON** to back up and **⭱ Import JSON** to restore.

The team-shared live version is hosted as a Claude artifact.
